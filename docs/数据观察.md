# 数据观察笔记
> Patent Infringement Check App
> Week 1

## 数据
- Patent data `patents.json`:共 **10100** 条专利。
- Company data `company_product_data.json`:共 **88** 家公司,每家公司**恰好 10 个产品**。

## 观察结论
**Q1. 专利对象有哪些字段?**
共 25 个字段:id、publication_number、title、ai_summary、raw_source_url、assignee、inventors、priority_date、application_date、grant_date、abstract、description、claims、jurisdictions、classifications、application_events、citations、image_urls、landscapes、created_at、updated_at、publish_date、citations_non_patent、provenance、attachment_urls。

**Q2. 哪些字段是「字符串套 JSON」?**
- `inventors`
- `claims`
- `classifications`
- `citations`
- `image_urls`

**Q3. 有没有 assignee 为空的专利?**
有，共 15 条专利的 assignee 为空。

**Q4. 产品的 description 是什么风格?**
基本都是简短英文的功能描述,格式基本一致
- Walmart Shopping App :: Mobile application with integrated shopping list and advertisement features
- Scan & Go :: Mobile app that allows adding items to list while scanning

**Q5. 哪家公司产品和哪个专利天然相关?**
专利 US-RE49889-E1（Adadapted 公司）与 Walmart 的产品高度相似，尤其是:
- Smart Shopping List
- Quick Add from Ads
